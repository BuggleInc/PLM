POSIX world

In this universe, your program runs in a simulated system. Its regular files and its network connections are part of the world, and the other programs follow a script. Your program uses them through file descriptors, as on a real UNIX system: the descriptors 0, 1 and 2 designate the standard input, output and error (STDIN_FILENO, STDOUT_FILENO and STDERR_FILENO), and each new descriptor is the smallest free number.

The system functions behave as their real counterparts, with the same signatures. They return -1 on failure, and set errno to the reason of the failure. Only IPv4 TCP sockets are supported. The output functions of stdio.h on the standard streams (printf(), fprintf() on stdout or stderr, puts(), fputs(), putchar() and perror()) write on the standard output and error of the world, without buffering.

Provided functions

  • int socket(int domain, int type, int protocol): creates a socket (AF_INET and SOCK_STREAM only).
  • int bind(int fd, const struct sockaddr* addr, socklen_t len): binds the socket to a local port.
  • int listen(int fd, int backlog): accepts the incoming connections on the bound socket.
  • int accept(int fd, struct sockaddr* addr, socklen_t* len): waits for an incoming connection, and returns a new descriptor for it.
  • int connect(int fd, const struct sockaddr* addr, socklen_t len): connects the socket to a server.
  • ssize_t send(int fd, const void* buf, size_t len, int flags) and ssize_t recv(int fd, void* buf, size_t len, int flags): send and receive data on a connected socket.
  • int shutdown(int fd, int how): closes one direction of the connection, or both.
  • int open(const char* path, int flags, ...): opens a file (O_RDONLY, O_WRONLY or O_RDWR, combined with O_CREAT, O_TRUNC or O_APPEND).
  • ssize_t read(int fd, void* buf, size_t count) and ssize_t write(int fd, const void* buf, size_t count): read and write data on any descriptor.
  • int close(int fd): closes the descriptor.
  • unsigned int sleep(unsigned int seconds): waits for the given amount of seconds.
