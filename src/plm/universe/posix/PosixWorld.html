POSIX world

In this universe, your program runs in a simulated system. Its regular files and its network connections are simulated within the PLM as parts of the world, and the other programs follow a script, or are servers of real protocols. [!c]Your program uses them through file descriptors, as on a real UNIX system: the descriptors 0, 1 and 2 designate the standard input, output and error (STDIN_FILENO, STDOUT_FILENO and STDERR_FILENO), and each new descriptor is the smallest free number.[/!][!python|java|scala]Your program uses them as on a real system, while the world shows the file descriptors behind them: the descriptors 0, 1 and 2 designate the standard input, output and error, and each new descriptor is the smallest free number.[/!] Only IPv4 TCP connections are supported.

The time of the world only advances when your program waits, for example for data that did not arrive yet. If your program and the other programs all wait for each other, the world stops your program and reports this deadlock, instead of letting it wait forever.

[!c]

The system functions behave as their real counterparts, with the same signatures. They return -1 on failure, and set errno to the reason of the failure. The output functions of stdio.h on the standard streams (printf(), fprintf() on stdout or stderr, puts(), fputs(), putchar() and perror()) write on the standard output and error of the world, without buffering.

Provided functions

  • int socket(int domain, int type, int protocol): creates a socket (AF_INET and SOCK_STREAM only).
  • int bind(int fd, const struct sockaddr* addr, socklen_t len): binds the socket to a local port.
  • int listen(int fd, int backlog): accepts the incoming connections on the bound socket.
  • int accept(int fd, struct sockaddr* addr, socklen_t* len): waits for an incoming connection, and returns a new descriptor for it.
  • int connect(int fd, const struct sockaddr* addr, socklen_t len): connects the socket to a server.
  • ssize_t send(int fd, const void* buf, size_t len, int flags) and ssize_t recv(int fd, void* buf, size_t len, int flags): send and receive data on a connected socket.
  • int shutdown(int fd, int how): closes one direction of the connection, or both.
  • int open(const char* path, int flags, ...): opens a file (O_RDONLY, O_WRONLY or O_RDWR, combined with O_CREAT, O_TRUNC or O_APPEND).
  • ssize_t read(int fd, void* buf, size_t count) and ssize_t write(int fd, const void* buf, size_t count): read and write data on any descriptor.
  • int close(int fd): closes the descriptor.
  • int unlink(const char* path): removes the file.
  • FILE* fopen(const char* path, const char* mode) and FILE* fdopen(int fd, const char* mode): give a stream of stdio.h on a file or on any descriptor, such as a socket, buffered as usual, to use it with fgets(), fscanf(), fprintf() or fflush().
  • unsigned int sleep(unsigned int seconds): waits for the given amount of seconds.
[/!] [!python]

The usual modules act on the world: socket, the file functions of os, open() and time.sleep(). The failures raise the usual exceptions, such as ConnectionRefusedError or FileNotFoundError. print() writes on the standard output of the world, and sys.stderr on its standard error.

Provided functions

  • socket.socket(): creates an IPv4 TCP socket. A with block closes it at its end.
  • sock.connect((host, port)): connects the socket to a server.
  • sock.bind((host, port)): binds the socket to a local port (the empty host "" standing for every interface), and sock.listen() accepts the incoming connections on it.
  • sock.accept(): waits for an incoming connection, and returns a pair whose first element is a new socket for it.
  • sock.send(data), sock.sendall(data) and sock.recv(size): send and receive bytes on a connected socket. recv() returns b"" at the end of the stream.
  • sock.makefile(mode): gives a file on the socket, buffered as usual, such as sock.makefile("rb") whose readline() returns the next line.
  • sock.shutdown(how): closes one direction of the connection (socket.SHUT_RD or socket.SHUT_WR), or both (socket.SHUT_RDWR), and sock.close() closes the socket.
  • socket.create_connection((host, port)) and socket.create_server((host, port)): give a socket connected to a server, or listening on a local port.
  • open(path, mode): opens a file of the world, in binary or text mode.
  • os.open(path, flags), os.read(fd, size), os.write(fd, data), os.close(fd) and os.fdopen(fd, mode): work on the descriptors, as their C counterparts.
  • os.unlink(path) or os.remove(path): removes the file.
  • time.sleep(seconds): waits for the given amount of whole seconds.
[/!] [!java|scala]

The usual classes act on the world, with the interface of the JDK: Socket, ServerSocket, Thread.sleep() and the classes reading and writing files. The failures throw the usual exceptions, such as ConnectException or FileNotFoundException. [!java]System.out[/!][!scala]println()[/!] writes on the standard output of the world, and System.err on its standard error.

Provided classes

  • new Socket(host, port): creates a socket connected to a server (or new Socket(), then connect(new InetSocketAddress(host, port))).
  • socket.getInputStream[!java]()[/!] and socket.getOutputStream[!java]()[/!]: give the streams to receive and send bytes on a connected socket, to wrap for example in a BufferedReader or a PrintWriter. The input stream returns -1 at the end of the stream.
  • socket.shutdownInput() and socket.shutdownOutput(): close one direction of the connection, and socket.close() closes the socket.
  • new ServerSocket(port): creates a socket listening on a local port (or new ServerSocket(), then bind(new InetSocketAddress(port))), whose accept() waits for an incoming connection and returns a new Socket for it.
  • new FileInputStream(path), new FileOutputStream(path, append), new FileReader(path), new FileWriter(path, append) and new PrintWriter(path): open a file of the world.
  • Files.readString(path), Files.readAllBytes(path), Files.readAllLines(path), Files.writeString(path, text), Files.write(path, bytes), Files.delete(path) and Files.deleteIfExists(path): read, write or remove a whole file, designated by Path.of(name).
  • Thread.sleep(milliseconds): waits for the given amount of milliseconds, rounded up to whole seconds.
