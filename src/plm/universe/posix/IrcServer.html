The IRC protocol

The IRC server of this world, named irc.buggleinc.com, follows the RFC 2812 as the usual servers. Its clients register with a nickname, join channels and talk there or in private with the other members.

Framing

Every message is a line ended by the two bytes \r\n (CR and LF, 13 and 10). The server sends its lines with \r\n, and accepts the lines of the client ended by \n alone. The network does not keep the limits of the lines: a single recv() may return several lines, or only the beginning of a line whose end is still on its way. The client must thus keep what it received until a \r\n ends the line.

A line is made of an optional prefix starting with :, which tells who sends it (the lines of the server always have one: the name of the server, or nick!user@host for a member), then of a command (a word, or the three digits of a numeric reply), then of its parameters separated by spaces. The last parameter may start with :, to contain spaces up to the end of the line. The commands are case-insensitive.

Commands

NICK nicknameGives the nickname of the client: up to 30 letters, digits, dashes or characters among []\`_^{|}, not starting with a digit nor a dash. Once registered, the server confirms a change with :old!user@host NICK :new.
USER username mode unused :real nameGives the user name of the client (the first parameter), with three other parameters that the server ignores, such as USER bob 0 * :Bob the buggle.
JOIN #channelJoins a channel (several ones separated by commas). The server confirms with :nick!user@host JOIN #channel, then gives the topic (332) and the members of the channel (353 and 366). Joining an unknown channel creates it, without topic.
PART #channel :reasonLeaves a channel, confirmed with :nick!user@host PART #channel (followed by the reason, if any).
PRIVMSG target :textSends a text to a joined channel, or to a member in private. The server does not send back the texts of the client.
NAMES #channelLists the members of a channel (353 and 366).
PING tokenAsks the server to answer :irc.buggleinc.com PONG irc.buggleinc.com :token.
QUIT :reasonLeaves the server, which answers ERROR :Closing Link: 10.0.0.10 (Client Quit) (or (Quit: reason)) and closes the connection.

The client registers by sending NICK and USER, in any order. Once both are given, the server sends its welcome: the replies 001 to 004, then the message of the day (375, 372 and 376). Before that, the server only accepts NICK, USER, PING and QUIT.

The other members speak in the lines that the server sends to the client, such as :Alice!alice@buggleinc.com PRIVMSG #welcome :Hello! on a channel, or :Alice!alice@buggleinc.com PRIVMSG yournick :Hello! in private. They start talking on a channel once the client joined it, and may answer a private message after a while.

Replies and errors

The numeric replies have the form :irc.buggleinc.com code target parameters, where the target is the nickname of the client, or * before it has one. The errors do not close the connection.

401target :No such nick/channelThe target of PRIVMSG does not exist.
403#channel :No such channelThe name of the channel is invalid (it must start with #, without spaces nor commas), or PART names an unknown channel.
404#channel :Cannot send to channelThe client did not join the channel it talks to.
409:No origin specifiedPING without token.
411:No recipient given (PRIVMSG)PRIVMSG without target.
412:No text to sendPRIVMSG without text.
421COMMAND :Unknown commandThe command (given in upper case) does not exist.
431:No nickname givenNICK without nickname.
432nickname :Erroneous NicknameThe nickname contains forbidden characters, or is too long.
433nickname :Nickname is already in useSomeone else has that nickname, whatever its case.
442#channel :You're not on that channelPART of a channel that the client did not join.
451:You have not registeredA command that needs the client to be registered.
461COMMAND :Not enough parametersUSER, JOIN or PART lacks parameters.
462:You may not reregisterUSER after the registration.

Example session

In this session, the channel #lobby has the topic "Say hello!" and Alice as only member, who speaks two seconds after the client joined. The lines starting with C: are sent by the client, and those starting with S: by the server. These prefixes are not part of the data, and \r\n stands for the two bytes ending each line.

C: NICK student\r\n
C: USER student 0 * :A student\r\n
S: :irc.buggleinc.com 001 student :Welcome to the BuggleInc IRC Network student!student@10.0.0.10\r\n
S: :irc.buggleinc.com 002 student :Your host is irc.buggleinc.com, running version plm-ircd-1.0\r\n
S: :irc.buggleinc.com 003 student :This server was created Mon Jan 1 2024 at 00:00:00 UTC\r\n
S: :irc.buggleinc.com 004 student irc.buggleinc.com plm-ircd-1.0 io ntk\r\n
S: :irc.buggleinc.com 375 student :- irc.buggleinc.com Message of the day - \r\n
S: :irc.buggleinc.com 372 student :- Be nice with the other buggles, and enjoy your stay!\r\n
S: :irc.buggleinc.com 376 student :End of /MOTD command.\r\n
C: JOIN #lobby\r\n
S: :student!student@10.0.0.10 JOIN #lobby\r\n
S: :irc.buggleinc.com 332 student #lobby :Say hello!\r\n
S: :irc.buggleinc.com 353 student = #lobby :Alice student\r\n
S: :irc.buggleinc.com 366 student #lobby :End of /NAMES list.\r\n
S: :Alice!alice@buggleinc.com PRIVMSG #lobby :Hello everybody!\r\n
C: PRIVMSG #lobby :Hello Alice!\r\n
C: QUIT\r\n
S: ERROR :Closing Link: 10.0.0.10 (Client Quit)\r\n
