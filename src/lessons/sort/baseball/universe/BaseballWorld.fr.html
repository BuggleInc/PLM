Baseball multicolore

Les couleurs sont représentées comme des entiers, entre 0 et nombre de bases - 1. Le trou est représenté par la valeur spéciale -1. La couleur de chaque base est son rang, ce qui fait que la base 1 est de couleur 1. Dans l'interface graphique, la base 0 est la bleue foncée tandis que la base 1 est celle fuscia.

Une fois que tous les joueurs du terrain sont chez eux, le trou se trouve dans la dernière base, celle de rang getNombreBases()-1.
