Algoritmos de Ordenação

Esta lição permite a experimentação com alguns algoritmos de ordenação clássicos (e algumas variações menos comuns deles). E temos um duplo objetivo: você pode primeiro compreender melhor a ideia destes algoritmos escrevendo eles por si só. Mas mesmo se você não codificar os algoritmos, você pode usar o modo de demonstração para organizar "corridas" entre os algoritmos para experimentar na prática o que significam diferentes complexidades assintóticas.
