Framing by nesting: XMPP

You now have everything to meet the friend of Bob: the address of the XMPP server (from the DNS), its port (from Bob, through your echo server), your account on it (from Alice), and the address of the chat room (from Bob, on IRC). XMPP (also known as Jabber) is the protocol of instant messaging standardized by the IETF, used by many chat services and by the online games and the connected objects that need to exchange messages.

XMPP frames its messages in yet another way. A connection carries a single XML document in each direction, called a stream, which only ends when the connection ends. The messages, called stanzas, are the elements directly inside the root of this document. There is no length before them and no line end after them: a stanza ends when its first tag gets closed, which requires counting how deep you are in the nesting of the elements. The data still arrives in packets cut anywhere, as with IRC. The XMPP server of this world is documented in the world documentation (Ctrl-H): read it before starting.

[!c]

The C library has no XML parser, so you will frame the stanzas by hand: scan the received bytes, count the depth of the nesting at each tag, and give the stanza once the depth gets back to the one of the stream. Here are the functions involved, besides the ones of the previous exercises. Check the manpages for more info.

  1. void* memmove(void* dest, const void* src, size_t n) copies n bytes, even when the two areas overlap, as when you remove the beginning of a buffer.
  2. int sprintf(char* str, const char* format, ...) writes as printf() into an array, and returns the number of bytes written: the format %c with the value 0 writes a zero byte.
  3. char* strstr(const char* haystack, const char* needle) and char* strchr(const char* s, int c) find a text or a character in a string.
[/!] [!python]

Python reads XML as it arrives, with the parser XMLPullParser of the module xml.etree.ElementTree. Check its documentation for more info.

  1. parser = ElementTree.XMLPullParser(events=("start", "end")) creates a parser telling when each element starts and ends.
  2. parser.feed(data) gives it some bytes, wherever they are cut, and parser.flush() makes it parse them at once (it may otherwise wait for more data before reading the end of a tag).
  3. parser.read_events() gives the pairs (event, element) of what was parsed since its last call. The element of an event "end" is complete: element.tag is its name, preceded by its namespace between braces (such as {jabber:client}message), element.get("from") is the value of its attribute from (or None), element.find("{jabber:client}body") is its child element body (or None), and element.text is its text, with the references such as &lt; already decoded.
  4. base64.b64encode(data) gives the base64 of some bytes, as bytes.
[/!]

  • The base64 writes each group of 3 bytes (24 bits) as 4 characters of 6 bits each, completed by = at the end. This function writes the base64 of length bytes into out:

    void base64(const unsigned char* data, int length, char* out)
{
  const char* digits = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/";
  for (int i = 0; i < length; i += 3) {
    int n  = data[i] << 16 | (i + 1 < length ? data[i + 1] << 8 : 0) | (i + 2 < length ? data[i + 2] : 0);
    *out++ = digits[n >> 18 & 63];
    *out++ = digits[n >> 12 & 63];
    *out++ = i + 1 < length ? digits[n >> 6 & 63] : '=';
    *out++ = i + 2 < length ? digits[n & 63] : '=';
  }
  *out = '\0';
}

    The credentials hold zero bytes, so they are not a string: keep their length, as given by sprintf(credentials, "%cnewcomer%c%s", 0, 0, password).

  • Count the depth: the header of the stream opens the depth 1, each opening tag of a stanza goes one deeper, and each closing tag one back; a tag ending with /> opens and closes its element at once. The stanza is whole when the depth gets back to 1. [!c]Inside a tag, the values between quotes may hold a / or a > (as in from='robots@conference.buggleinc.lan/Karel'), which mean nothing there. Keep the bytes that follow the stanza for the next one.[/!][!python]Count the events "start" and "end" of the parser, and keep the element of an event "end" that brings the depth back to 1.[/!]

    • [!python] 
  • def stanzas(sock):
    parser = ElementTree.XMLPullParser(events=("start", "end"))
    depth = 0
    while True:
        for event, element in parser.read_events():
            if event == "start":
                depth += 1
            else:
                depth -= 1
                if depth == 1:  # back in the stream, at the end of one of its children
                    yield element
        data = sock.recv(4096)
        if not data:  # the end of the stream
            return
        parser.feed(data)
        parser.flush()

    Use it as the generator of lines of the IRC exercise: reader = stanzas(sock), then stanza = next(reader).

  • char buffer[65536]; /* the data received and not given yet */
int length  = 0;    /* how many bytes it holds */
int scanned = 0;    /* how many of them were scanned */
int depth   = 0;    /* 0 outside the stream, 1 in the stream, 2 or more in a stanza */
int tag     = -1;   /* where the tag being scanned starts, or -1 in a text */
char quote  = 0;    /* the quote of the value being scanned, or 0 */
int start   = 0;    /* where the stanza being scanned starts */

/* Writes the next stanza into stanza (of that size), ended by a zero byte, and returns 1, or 0 at the end of the stream */
int next_stanza(int sock, char* stanza, int size)
{
  while (1) {
    for (; scanned < length; scanned++) {
      char c = buffer[scanned];
      if (tag < 0) {          /* in a text, or between the stanzas */
        if (c == '<')
          tag = scanned;
      } else if (quote != 0) { /* in the value of an attribute */
        if (c == quote)
          quote = 0;
      } else if (c == '\'' || c == '"')
        quote = c;
      else if (c == '>') {    /* the end of a tag */
        int stanza_ended = 0;
        if (buffer[tag + 1] == '/') {        /* a closing tag */
          depth--;
          stanza_ended = depth == 1;
        } else if (buffer[tag + 1] != '?') { /* an opening tag, unless the XML declaration */
          if (depth == 1)
            start = tag;
          if (buffer[scanned - 1] == '/')    /* an empty element, as <x/> */
            stanza_ended = depth == 1;
          else
            depth++;
        }
        tag = -1;
        if (depth == 0)       /* </stream:stream> */
          return 0;
        if (stanza_ended) {
          int n = scanned + 1 - start;
          if (n >= size)
            n = size - 1;
          memcpy(stanza, buffer + start, n);
          stanza[n] = '\0';
          length -= scanned + 1; /* forget everything up to the end of the stanza */
          memmove(buffer, buffer + scanned + 1, length);
          scanned = 0;
          return 1;
        }
      }
    }
    int received = recv(sock, buffer + length, sizeof(buffer) - length, 0);
    if (received <= 0)        /* the end of the stream, or an error */
      return 0;
    length += received;
  }
}

    [!c] 
    void decode(char* text)
{
  const char* references[] = {"&lt;", "&gt;", "&amp;", "&apos;", "&quot;"};
  const char* characters   = "<>&'\"";
  char* out                = text;
  while (*text != '\0') {
    int found = 0;
    for (int i = 0; i < 5 && !found; i++)
      if (strncmp(text, references[i], strlen(references[i])) == 0) {
        *out++ = characters[i];
        text += strlen(references[i]);
        found = 1;
      }
    if (!found)
      *out++ = *text++;
  }
  *out = '\0';
}
