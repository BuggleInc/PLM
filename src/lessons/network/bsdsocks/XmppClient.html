Framing by nesting: XMPP

You now have everything to meet the friend of Bob: the address of the XMPP server (from the DNS), its port (from Bob, through your echo server), your account on it (from Alice), and the address of the chat room (from Bob, on IRC). If not, please return to the previous exercises to follow the story without cheating :)

In this exercise, we will discover XMPP, that is also known as Jabber. It is the protocol of instant messaging standardized by the IETF, used by many chat services and by the online games and the connected objects that need to exchange messages. XMPP frames its messages in yet another way. A connection carries a single XML document in each direction, called a stream, which only ends when the connection ends. The messages, called stanzas, are the elements directly inside the root of this document. There is no length before them and no line end after them: a stanza ends when its first tag gets closed, which requires counting how deep you are in the nesting of the elements. Something similar would have been possible with correctly parenthesized expressions: any stanza starts with an opening parenthesis ( and you know that the message is complete only when you find the corresponding ).

An XML primer

An XML tag has more information embedded than a single parenthesis: a name and attributes. The XML syntax is verbose and not very pleasant to read as a human, but it is very regular and somewhat easy to parse. The simplest form of tag is the tag name between angle brackets. <a> is the a tag. You can add attributes to any tag, as in <a href="http://buggleinc.com"> which adds an attribute of name href and value http://buggleinc.com. Tags can also be used to enclose some text, as in <b>some text</b>. The first tag is said to be an opening tag because it does not start with </ while the second tag is said to be a closing tag because it actually has a / between the angle bracket and the tag name (so the two a tags used earlier are opening tags too). Finally, some tags are self-closing such as <br/>. They are both the opening and the closing tag at once, because they have a / after the tag name and right before the closing angle bracket >.

The last piece of XML that you will need in this exercise is the solution to escape the < and > in the input data. In the text that lays outside of the tags, XML escapes < as &lt; (spelled "the less-than entity"), while > may or may not be escaped (as &gt; -- greater-than). Indeed, escaping > in the text is useless: there is no tag to end if you did not encounter a < to end the text and start a tag. & itself is encoded as &amp;. The > may also appear in the attribute values (but not in their name, and a < never appears there), but that's OK because attributes must be enclosed between simple quotes '...' or double quotes "...". A quote within an attribute value is written as an entity (&apos; for ' and &quot; for "), so a value always ends at the next occurrence of the quote that started it. Don't worry, this is a lesson on networking, so your code does not need to handle angle brackets in attribute values. Likewise, there is no <![CDATA[...]]> construct in this exercise, even if it's a great way to escape some content from the XML parsing.

How to proceed

The goal of the exercise is to open a socket to the server specified as a parameter, send the header of your stream according to the protocol documentation, and parse the answers that you get. The server starts its own stream with the XML declaration <?xml version='1.0'?>, which is neither an opening nor a closing tag, then with its header <stream:stream ...>, an opening tag that only gets closed at the end of the connection: the messages are the elements inside this stream, possibly preceded by some spaces. If the received message starts with a self-closing tag (as in <br/>) then the message is complete and must be handled according to the XMPP protocol, which is documented in the world documentation (Ctrl-H): read it before starting. If the message starts with an opening tag, then you must fetch data from the network until you got the closing tag that brings you back to the depth of the stream, because the data still arrives in packets cut anywhere, as with IRC. Count the depth: a message may contain elements with its own name, so the first closing tag with the right name does not always end it.

There are plenty of available XML parsers[!python|java|scala], including in the [!thelang/] standard library[/!], but we will do the parsing manually to better understand how the framing goes in this case. This is not as complex as it sounds, because we can assume that the server always sends valid XML stanzas, without angle brackets in attribute values or anything complex. Yet, it is advised to split your code in two layers to increase its readability.

The framing reads the network and cuts the stanzas. This is the core of this exercise. It reads the bytes one by one from a buffered stream, adds them to the stanza being built, and counts the depth at each tag: the byte after a < tells a closing tag (/) from the XML declaration (?) and from an opening tag, and the byte before a > tells a self-closing tag (/). The stanza is complete when its last tag brings the depth back to the one of the stream. The XML declaration, the header of the stream and the spaces between the stanzas are not part of any stanza. [!python]Write it as a generator: a function that yields each stanza in turn as a text, and that the rest of your code uses with next() or in a for loop.[/!] [!java|scala]Write it as a method nextStanza() returning the next stanza as a String, or null at the end of the stream. It plays the role of an iterator (what Python calls a generator): each call goes on reading where the previous one stopped.[/!] [!c]Write it as a function writing the next stanza into an array, and returning 0 at the end of the stream: each call goes on reading where the previous one stopped.[/!] The framing is built upon a buffered stream from the standard library that hides the packets, using [!c]fdopen(), fgetc() and ungetc()[/!] [!python]sock.makefile("rb"), read(1) and peek()[/!] [!java|scala]PushbackInputStream and BufferedInputStream[/!] (see below).

The application, at the top, speaks XMPP using the features proposed by the framing layer. It sends your stanzas, and looks in the stanzas received for what the scenario needs: who sent a message (its attribute from) and what it says (the text of its own <body>, whose entities must be decoded). It never sees a packet, nor counts a depth.

Here are the functions involved, besides the ones of the previous exercises. Check the manpages for more info.

  1. FILE* fdopen(int fd, const char* mode) gives a buffered stream on a descriptor, such as your socket. Open it with the mode "r", to read only: keep send() to write on the socket. fclose() closes the stream and the socket at once: do not close() the socket after it.
  2. int fgetc(FILE* stream) returns the next byte of the stream, or EOF at its end. Do not use fread() to read a stanza: it waits until it has all the bytes asked for, which may never come.
  3. int ungetc(int c, FILE* stream) puts the byte c back into the stream, so that the next fgetc() returns it again. It lets you look at the next byte without taking it: to skip the spaces between the stanzas, read until a byte that is not a space, then put it back, so that the stanza starts with its <.
  4. int snprintf(char* str, size_t size, const char* format, ...) writes as printf() into an array of size size, and returns the number of bytes written. This function correctly truncates the output to never overflow the buffer.
  5. char* strstr(const char* haystack, const char* needle) and char* strchr(const char* s, int c) find a text or a character in a string.

  • The base64 writes each group of 3 bytes (24 bits) as 4 characters of 6 bits each, completed by = at the end. This function writes the base64 of length bytes into out:

    void base64(const unsigned char* data, int length, char* out)
{
  const char* digits = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/";
  for (int i = 0; i < length; i += 3) {
    int n  = data[i] << 16 | (i + 1 < length ? data[i + 1] << 8 : 0) | (i + 2 < length ? data[i + 2] : 0);
    *out++ = digits[n >> 18 & 63];
    *out++ = digits[n >> 12 & 63];
    *out++ = i + 1 < length ? digits[n >> 6 & 63] : '=';
    *out++ = i + 2 < length ? digits[n & 63] : '=';
  }
  *out = '\0';
}

    The credentials hold zero bytes, so they are not a string: keep their length, as given by snprintf(credentials, buffsize, "%cnewcomer%c%s", 0, 0, password).

  • It keeps an array of the bytes received but not read yet, with the position of the next one to read. When this array is empty, a single recv() fills it with everything that arrived meanwhile (a packet, or several), up to its size. Then each call returns the next byte from the array, without asking anything from the network. Reading byte by byte thus costs one system call per packet, not one per byte, and the packets do not matter to the code reading the stream.

    Putting a byte back (as [!c]ungetc()[/!][!python]peek()[/!][!java|scala]unread()[/!] does) simply moves the position of the next byte one step back, storing the byte there. When this position is already at the start of the array while some bytes remain to read, the stream first shifts them one step further to make room.

    Here is how you could write such a stream yourself, without putting bytes back:

    [!c] 
    struct reader {
  int sock;
  char data[4096];
  int start, end; /* the bytes received but not read yet are data[start] to data[end - 1] */
};

/* The next byte, or -1 at the end of the stream */
int reader_getc(struct reader* r)
{
  if (r->start == r->end) {
    int received = recv(r->sock, r->data, sizeof(r->data), 0);
    if (received <= 0)
      return -1;
    r->start = 0;
    r->end   = received;
  }
  return (unsigned char)r->data[r->start++];
}

    Create it with struct reader r = {sock, {0}, 0, 0};, then call reader_getc(&r) where you would call fgetc(in).

    [/!] [!python] 
    class Reader:
    def __init__(self, sock):
        self.sock = sock
        self.data = b""
        self.pos = 0  # the next byte to read in data

    def read(self):
        """The next byte, or None at the end of the stream"""
        if self.pos == len(self.data):
            self.data = self.sock.recv(4096)
            self.pos = 0
            if not self.data:
                return None
        self.pos += 1
        return self.data[self.pos - 1]

    Its read() returns the byte as an integer, where stream.read(1) returns it as a bytes.

    class Reader {
  private final InputStream in;
  private final byte[] data = new byte[4096];
  private int pos = 0, end = 0; // the bytes received but not read yet are data[pos] to data[end - 1]

  Reader(InputStream in) { this.in = in; }

  /** The next byte, or -1 at the end of the stream */
  int read() throws IOException
  {
    if (pos == end) {
      int received = in.read(data, 0, data.length);
      if (received <= 0)
        return -1;
      pos = 0;
      end = received;
    }
    return data[pos++] & 0xff;
  }
}

  • Count the depth: the header of the stream opens the depth 1, each opening tag of a stanza goes one deeper, each closing tag one back, and a tag ending with /> opens and closes its element at once. The stanza is whole when a tag brings the depth back to 1, or when a tag ending with /> comes at the depth 1. Remember the byte after each < and the byte before each >: they tell the kind of the tag. The XML declaration (<?...?>) changes nothing, and the closing of the stream (</stream:stream>) brings the depth back to 0.

  • [!c] 
    int depth = 0; /* 0 before the header of the stream, 1 inside it, 2 or more inside a stanza */

/* Writes the next stanza of the stream into stanza (an array of that size), ended by a zero byte, and returns 1, or 0 at the
 * end of the stream */
int next_stanza(FILE* in, char* stanza, int size)
{
  int length = 0, kind = 0, previous = 0; /* kind: the byte after the < of the tag being read, or 0 out of a tag */
  while (1) {
    int c;
    if (depth == 1 && length == 0) { /* the spaces between the stanzas */
      while ((c = fgetc(in)) == ' ' || c == '\t' || c == '\r' || c == '\n')
        ;
      ungetc(c, in);
    }
    c = fgetc(in);
    if (c == EOF)
      return 0;
    if (length < size - 1)
      stanza[length++] = c;
    if (previous == '<')
      kind = c;
    else if (c == '>' && kind != 0) { /* the end of a tag */
      int before = depth;
      if (kind == '/') /* a closing tag */
        depth--;
      else if (kind != '?' && previous != '/') /* an opening tag, unless the XML declaration or a self-closing tag */
        depth++;
      kind = 0;
      if (before == 0) /* the XML declaration or the header of the stream, which are no stanzas */
        length = 0;
      else if (depth == 0) /* </stream:stream> */
        return 0;
      else if (depth == 1) {
        stanza[length] = '\0';
        return 1;
      }
    }
    previous = c;
  }
}

    private int depth = 0; // 0 before the header of the stream, 1 inside it, 2 or more inside a stanza

/** The next stanza of the stream, once it arrived whole, or null at the end of the stream */
String nextStanza(PushbackInputStream in) throws IOException
{
  StringBuilder stanza = new StringBuilder();
  int kind = 0, previous = 0; // kind: the byte after the < of the tag being read, or 0 out of a tag
  while (true) {
    int c;
    if (depth == 1 && stanza.length() == 0) { // the spaces between the stanzas
      while ((c = in.read()) == ' ' || c == '\t' || c == '\r' || c == '\n')
        ;
      if (c != -1)
        in.unread(c);
    }
    c = in.read();
    if (c == -1)
      return null;
    stanza.append((char)c);
    if (previous == '<')
      kind = c;
    else if (c == '>' && kind != 0) { // the end of a tag
      int before = depth;
      if (kind == '/') // a closing tag
        depth--;
      else if (kind != '?' && previous != '/') // an opening tag, unless the XML declaration or a self-closing tag
        depth++;
      kind = 0;
      if (before == 0) // the XML declaration or the header of the stream, which are no stanzas
        stanza.setLength(0);
      else if (depth == 0) // </stream:stream>
        return null;
      else if (depth == 1)
        return stanza.toString();
    }
    previous = c;
  }
}

    [!c] 
    /* Decodes the references of the text in place, such as &lt; into < */
void decode(char* text)
{
  const char* references[] = {"&lt;", "&gt;", "&amp;", "&apos;", "&quot;"};
  const char* characters   = "<>&'\"";
  char* out                = text;
  while (*text != '\0') {
    int found = 0;
    for (int i = 0; i < 5 && !found; i++)
      if (strncmp(text, references[i], strlen(references[i])) == 0) {
        *out++ = characters[i];
        text += strlen(references[i]);
        found = 1;
      }
    if (!found)
      *out++ = *text++;
  }
  *out = '\0';
}
